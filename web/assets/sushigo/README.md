# Sushi Go! card images

These 13 PNGs are byte-for-byte copies of `data/sushigo/` in the public
TabletopGames reference (`GAIGResearch/TabletopGames`). They are used for card
faces and the card back in the browser. The [manifest](manifest.json) records
each original path, size and SHA-256 hash. The repository's MIT notice is
retained as [TAG-LICENSE.txt](TAG-LICENSE.txt). The public reference does not
provide separate per-image attribution in `data/sushigo/`.

No PNG in this directory was generated, edited or copied from the excluded
private repository. The browser still obtains card identities and visibility
from Rust observations; the images only present those facts.
